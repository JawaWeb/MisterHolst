# Mister Holst

Адаптивна односторінкова сторінка українською. Чисті HTML/CSS/JS, без збірки чи зовнішніх бібліотек.

## Запуск
Відкрийте index.html у браузері або розмістіть вміст dist на будь-якому статичному хостингу. Для локального HTTP: python -m http.server 8080.

## Замовлення
Форма локально показує фото (JPG/PNG/WEBP до 20 МБ), розраховує базову ціну та готує текст заявки. Користувач копіює заявку й сам надсилає її та оригінал фото в месенджері. Серверного приймання файлів або заявок немає; автоматичне надсилання потребує окремого бекенду.

## Контент
Ціни та телефон: https://misterholst.com/ru/ (перевірено 2026-11-02).
Telegram: посилання з офіційного сайту. Instagram: профіль, наданий у брифі.
Фото: офіційна галерея Mister Holst; права залишаються у власників. Картка картини за номерами містить приклад фотооснови, а не фото готового набору. Скріншоти відгуків Instagram не були доступні, тому використано реальні фото галереї без вигаданих цитат.
Місто виробництва не вказано через розбіжність між брифом (Івано-Франківськ) і сайтом (Суми); зазначено доставку до Івано-Франківська. Умови акції, міжнародної доставки й актуальність контактів потрібно підтверджувати у бізнесу.

## Редагування
Тексти, контакти, прайс: index.html. Числові ціни для розрахунку також у prices в app.js. Дизайн і адаптивність: style.css. Зображення: dist/assets.

## Studio edition
Локальні шрифти Manrope (SIL OFL), SVG-іконки, адаптивна типографіка, sticky-шапка, touch-зони від 44px, підтримка prefers-reduced-motion. Мобільний CTA ховається біля форми. Перевірено ширини 320, 390, 768 px без горизонтального переповнення, десктопне відображення та формування заявки з ціною 1899 грн.

## Перевірка перед передачею
Дивіться AUDIT.md: пріоритети проблем, виправлення, фактично виконані перевірки й обмеження. Фінальна версія підтримує власні розміри, перевірку декодування зображень, видалення фото та клавіатурну навігацію. Вбудовані шрифти мають ліцензію в assets/OFL-Manrope.txt.
